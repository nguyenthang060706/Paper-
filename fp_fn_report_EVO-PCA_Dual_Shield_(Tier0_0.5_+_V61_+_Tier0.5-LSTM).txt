212	## Boot Flow
213	
214	```
215	GRUB (Multiboot 1)
216	  └─ _start  [32-bit protected mode]
217	       ├─ Check CPUID / long-mode support
218	       ├─ Build identity-mapped page tables (PML4→PDPT→PD, 2 MiB huge pages)
219	       ├─ Enable PAE + EFER.LME, enable paging
220	       ├─ Load 64-bit GDT, far-jump to long mode
221	       └─ kernel_main(mb_magic, mb_info_phys)
222	            ├─ serial_init / vga_init / vga_clear
223	            ├─ gdt_init       — Ring 0/1 segments + 64-bit TSS
224	            ├─ idt_init       — 256 interrupt gates
225	            ├─ timer_init     — remap 8259 PIC; PIT → 100 Hz
226	            ├─ sti            — enable hardware interrupts
227	            ├─ syscall_init   — patch IDT[0x80] to DPL=1
228	            ├─ keyboard_init  — PS/2 scancode set 1
229	            ├─ process_init   — clear PCB table; init scheduler
230	            ├─ detect_cpu / detect RAM from multiboot
231	            ├─ pmm_init / vmm_init
232	            ├─ vfs_init / rawfs+ext2 mount /
233	            ├─ seed /tmp /home /bin /etc + initramfs_seed()
234	            ├─ minit_init
235	            ├─ proc_create(shell_main, RING_SERVICE) → proc_wake
236	            ├─ minit_watch(shell_main, "shell", shell)
237	            └─ sched_pick → proc_switch → shell_main
238	                 idle loop: minit_tick() + hlt
239	```

46	## 1. Boot Sequence
47	
48	`boot/boot.asm` is the Multiboot 1 entry point, loaded at physical address `0x100000` by GRUB.
49	
50	```
51	[32-bit protected mode]
52	_start:
53	  1. Verify CPUID support (toggle ID flag in EFLAGS)
54	  2. Verify long-mode support (CPUID leaf 0x80000001, bit 29)
55	  3. Build identity-mapped page tables:
56	       PML4[0] → PDPT
57	       PDPT[0] → PD
58	       PD[0..511] → 2 MiB huge pages (covers 0..1 GiB)
59	  4. Load PML4 into CR3
60	  5. Set CR4.PAE, CR4.OSFXSR, CR4.OSXMMEXCPT
61	  6. Set EFER.LME via MSR 0xC0000080
62	  7. Set CR0.PG (enable paging → activates long mode)
63	  8. Load 64-bit GDT stub
64	  9. Far-jump to long_mode_start (CS selector 0x08)
65	
66	[64-bit long mode]
67	long_mode_start:
68	  10. Zero BSS segment
69	  11. Call kernel_main(mb_magic, mb_info_phys)
70	```
71	
72	`kernel_main` initialises every subsystem in dependency order before creating the shell process and entering the idle loop.
73

76	## 2. Memory Layout
77	
78	### Physical Address Space (at boot)
79	
80	| Range | Contents |
81	|-------|----------|
82	| `0x000000 – 0x0FFFFF` | BIOS / legacy (not used) |
83	| `0x100000 – ~` | Kernel ELF loaded here by GRUB |
84	| Above kernel | Free RAM (tracked by PMM) |
85	
86	### Virtual Address Space (kernel)
87	
88	| Symbol | Address | Description |
89	|--------|---------|-------------|
90	| `.text` start | `0x100000` | Kernel code |
91	| `.data` / `.rodata` | after `.text` | Kernel data |
92	| `.bss` | after `.data` | Zero-init + heap |
93	| `_heap_start` | inside `.bss` | Start of allocator arena |
94	| `_heap_end` | `_heap_start + 64 MiB` | End of allocator arena |
95	
96	The heap is declared inside `.bss` (NOBITS ELF section) so it occupies no space in the binary on disk.
97	
98	### Linker-Exported Symbols
99	
100	```c
101	extern char _heap_start[];   /* first byte of heap arena */
102	extern char _heap_end[];     /* one past last byte       */
103	```
104	
105	Both used by `stdlib/malloc.c` to initialise the free-list.

109	## 3. Kernel Subsystems
110	
111	### 3.1 VGA Driver
112	
113	**File:** `kernel/vga.c`, `include/vga.h`
114	
115	Mode: 80×25 text, standard VGA MMIO at `0xB8000`. Cell format: `[attribute][char]` (2 bytes).
116	
117	```c
118	void vga_init(void);               /* set 80×25, upload font, set cursor style */
119	void vga_clear(void);              /* fill screen with spaces, colour 0x07     */
120	void kprint(const char *s);        /* print null-terminated string             */
121	void kprint_char(char c);          /* print single character                   */
122	void kprint_uint64(uint64_t n);    /* print decimal integer                    */
123	void vga_goto(size_t col, size_t row); /* move hardware cursor + update col/row */
124	```
125	
126	**Font:** 8×16 glyphs in `boot/font8x16.asm`. Uploaded to VGA plane 2 (0xA0000) at boot. Cell height set to 16 rows (register 0x09 = 0x0F), cursor at scanlines 14–15.
127	
128	**Colour:** `vga_color` global (`uint8_t`), set via `VGA_COLOR(fg, bg)` macro. JS apps can change it with the `setColor` binding.
129	
130	---
131	
132	### 3.2 GDT
133	
134	**File:** `kernel/gdt.c`, `include/gdt.h`
135	
136	| Index | Selector | Ring | Type |
137	|-------|----------|------|------|
138	| 0 | `0x00` | — | Null |
139	| 1 | `0x08` | 0 | 64-bit code |
140	| 2 | `0x10` | 0 | Data |
141	| 3 | `0x18` | 1 | 64-bit code (userland) |
142	| 4 | `0x20` | 1 | Data (userland) |
143	| 5–6 | `0x28` | 0 | 64-bit TSS (2 descriptors) |
144	
145	`gdt_flush()` (in `boot/gdt_flush.asm`) reloads all segment registers and performs a far-return to update CS.
146	
147	---
148	
149	### 3.3 IDT & Exceptions
150	
151	**File:** `kernel/idt.c`, `boot/isr_stubs.asm`
152	
153	256 interrupt gates, all installed at `idt_init()`. The stub macro in `isr_stubs.asm` pushes a uniform `int_frame_t` layout (error code + vector number) then calls the C handler.
154	
155	CPU exceptions (vectors 0–31) print the vector number and faulting RIP to VGA, then `hlt`.
156	
157	Hardware IRQs (vectors 32–47) are dispatched through the IRQ handler table. IRQ0 drives the timer; IRQ1 drives the keyboard.
158	
159	`int $0x80` (vector 128) is patched to DPL=1 by `syscall_init()` so Ring-1 code can invoke it without a GPF.
160	
161	---
162	
163	### 3.4 PIC & PIT Timer
164	
165	**File:** `kernel/timer.c`
166	
167	- 8259A PIC remapped: master → vectors 32–39, slave → vectors 40–47.
168	- PIT channel 0 programmed to 100 Hz (divisor 11932).
169	- `timer_ticks` and `timer_seconds` globals incremented by IRQ0 handler.
170	- `timer_gettime()` fills a `struct timespec` from tick counters.
171	
172	---
173	
174	### 3.5 PS/2 Keyboard
175	
176	**File:** `drivers/keyboard.c`, `include/keyboard.h`
177	
178	**`keyboard_getchar()`** — blocks until a printable ASCII key, returns `char`.
179	
180	**`keyboard_getkey()`** — blocks until any key, returns an `int`:
181	- Printable ASCII → returns the ASCII code directly.
182	- Extended keys (E0-prefixed scancodes) → returns a `KEY_*` constant (≥ 256).
183	- Ctrl+letter → returns 1–26.
184	- F1–F10 → returns `KEY_F1`–`KEY_F10`.
185	
186	See [Section 10](#10-keyboard-key-codes) for the full `KEY_*` table.
187

190	### 3.6 Process Manager & Scheduler
191	
192	**File:** `kernel/process.c`, `include/process.h`, `include/sched.h`
193	
194	Each process has a `process_t` PCB:
195	
196	```c
197	typedef struct process {
198	    uint64_t   rsp;             /* saved stack pointer (context switch) */
199	    uint64_t   rip;             /* entry point                          */
200	    uint32_t   pid;
201	    proc_state_t state;         /* PROC_UNUSED, READY, RUNNING, BLOCKED, ZOMBIE */
202	    uint8_t    ring;            /* RING_KERNEL=0, RING_SERVICE=1        */
203	    uint8_t    priority;
204	    uint32_t   quantum;
205	    char       name[PROC_NAME_LEN];
206	    /* … scheduling metadata … */
207	} process_t;
208	```
209	
210	**Scheduler:** Cooperative. `sched_pick()` selects the next runnable process (SJF + priority aging + exhaustion penalties). `proc_switch()` performs a context switch via `boot/ctx_switch.asm` (saves/restores callee-saved registers + RSP).
211	
212	**Key functions:**
213	
214	```c
215	process_t *proc_create(void (*entry)(void), const char *name, uint8_t ring, uint32_t quantum, uint32_t priority);
216	void        proc_wake(process_t *p);
217	void        proc_switch(process_t *p);
218	process_t  *proc_by_pid(uint32_t pid);   /* returns NULL if not found */
219	void        proc_destroy(process_t *p);
220	```
221

224	### 3.7 PMM & VMM
225	
226	**File:** `kernel/pmm.c`, `kernel/vmm.c`
227	
228	**PMM** tracks 4K physical frames using a bitmap derived from the Multiboot memory map. `pmm_alloc_frame()` returns a free physical page; `pmm_free_frame()` returns it to the pool.
229	
230	**VMM** initialises 4-level paging and records the initial CR3. Used as the foundation for future per-process address spaces.
231	
232	---
233	
234	### 3.8 minit — Process Supervisor
235	
236	**File:** `kernel/minit.c`, `include/minit.h`
237	
238	minit is NephilimOS's lightweight init. It is not a separate process — it runs inside the kernel idle loop, adding zero process overhead.
239	
240	**Configuration:**
241	
242	```c
243	#define MINIT_MAX_WATCH  16   /* max supervised processes */
244	#define MINIT_MAX_RETRY   3   /* restart attempts before giving up */
245	```
246	
247	**Watch table entry:**
248	
249	```c
250	typedef struct {
251	    void       (*entry)(void);      /* entry function used to re-spawn */
252	    char         name[PROC_NAME_LEN];
253	    uint32_t     pid;               /* PID of currently-running child  */
254	    uint8_t      retries;           /* restart attempts so far         */
255	    uint8_t      active;            /* 1 = slot in use                 */
256	} watch_t;
257	```
258	
259	**API:**
260	
261	```c
262	void minit_init(void);
263	int  minit_watch(void (*entry)(void), const char *name, process_t *p);
264	void minit_tick(void);   /* call from idle loop on each hlt iteration */
265	```
266	
267	**Behaviour per tick:**
268	1. For each active slot, call `proc_by_pid(w->pid)`.
269	2. If the process is alive (`state != PROC_UNUSED && state != PROC_ZOMBIE`), skip.
270	3. If dead and `retries < MINIT_MAX_RETRY`: increment retries, log the attempt, call `proc_create` + `proc_wake`, update `w->pid`.
271	4. If `retries >= MINIT_MAX_RETRY`: log "giving up", clear the slot.
272	
273	Currently the shell (`shell_main`) is the only watched process.

389	### 5.2 ext2 Implementation
390	
391	**File:** `fs/ext2.c`
392	
393	Block size: 1024 bytes. Single block group layout (the entire disk is one group).
394	
395	**Block layout within the group:**
396	
397	| Block | Contents |
398	|-------|----------|
399	| 0 | (unused — Multiboot convention) |
400	| 1 | Superblock |
401	| 2 | Block Group Descriptor (BGD) |
402	| 3 | Block bitmap |
403	| 4 | Inode bitmap |
404	| 5 … 5+N-1 | Inode table (N = ceil(max_inodes × 128 / 1024)) |
405	| 5+N … end | Data blocks |
406	
407	The BGD is written at block 2, bitmaps at blocks 3 and 4. This avoids the overlap that occurred when bitmaps were placed at `gbase+1` (same block as the BGD table).
408	
409	Overhead for the allocator: `5 + inode_table_blocks`.

494	## 6. Heap Allocator
495	
496	**File:** `stdlib/malloc.c`
497	
498	First-fit free-list allocator with immediate coalescing.
499	
500	**Block header (16 bytes):**
501	
502	```c
503	typedef struct block {
504	    size_t        size;    /* usable payload bytes (not including header) */
505	    uint32_t      free;    /* 1 = free, 0 = allocated                     */
506	    uint32_t      _pad;
507	    struct block *next;    /* next block in the list (NULL = end)          */
508	} block_t;
509	```
510	
511	**`malloc(n)`:** Walks the free list, finds the first block where `b->size >= n`. If the remainder after splitting is ≥ 32 bytes (header + 16 bytes minimum payload), splits the block. Otherwise allocates the whole block.
512	
513	**`free(ptr)`:** Marks the block free, then calls `coalesce()` which merges adjacent free blocks in a single linear pass.
514	
515	**`realloc(ptr, 0)`:** Equivalent to `free(ptr)`.  
516	**`realloc(ptr, n)`:** If the existing block is large enough, returns `ptr` unchanged. Otherwise `malloc` + `memcpy` + `free`.
517	
518	**Arena:** `_heap_start` to `_heap_end` (64 MiB). Initialised by `arena_init()` which creates a single free block covering the whole range. `arena_init()` is called lazily on the first `malloc`.
519	
520	MuJS compatibility: MuJS GC calls `realloc(ptr, 0)` to release memory. The free-list allocator handles this correctly; the former bump allocator did not, causing OOM after ~8 editor keystrokes.

527	
528	**File:** `kernel/js_runtime.c`, `external/include/mujs/`
529	
530	MuJS is compiled freestanding against `mujs_port.h` which maps `malloc`/`free`/`realloc` to the kernel allocator and stubs out POSIX I/O. The interpreter runs in Ring 0 kernel context during `SYS_JS_EXEC`.
531

533	
534	### 7.1.1 Signal Library
535	
536	**File:** `userland/signal.js` — injected automatically into every JS state before the app source runs. No import needed.
537	
538	A minimal reactive state library. All four primitives are available as globals.
539	
540	**`signal(initialValue)`**
541	
542	```javascript
543	var count = signal(0);
544	count.get();          // read current value
545	count.peek();         // read without being tracked (safe inside effects)
546	count.set(n);         // write; notifies subscribers (deferred during batch)
547	count.sub(fn);        // subscribe: fn(newValue, oldValue) called on change
548	```
549	
550	**`computed(fn)`**
551	
552	Read-only signal whose value is derived from other signals. Recomputes lazily on `.get()` when marked stale.
553	
554	```javascript
555	var label = computed(function() {
556	    return dirty.get() ? '[modified]' : '';
557	});
558	label.get();    // recomputes if dirty changed since last call
559	label.peek();   // returns cached value without recompute
560	```
561	
562	**`effect(signals, fn)`**
563	
564	Runs `fn` immediately, then re-runs it whenever any signal in the array changes.
565	
566	```javascript
567	effect([cx, cy], function() {
568	    drawStatusBar();
569	});
570	```
571	
572	**`batch(fn)`**
573	
574	Defers all subscriber notifications until `fn` returns. Each subscriber fires at most once per batch, with the final value. Essential when multiple signals change together.
575	
576	```javascript
577	batch(function() {
578	    cx.set(0);
579	    cy.set(cy.get() - 1);
580	    dirty.set(true);
581	});
582	// all three subscribers fire here, each exactly once
583	```
584	
585	Batches nest correctly — inner batches join the outer one.

731	`hist_get(offset)` — `offset=1` = most recent, `offset=2` = previous, etc.
732	
733	While browsing history with Up, the current live input is saved to `saved[]` and restored on Down back to position 0.

48	## 1. Boot Sequence
49	
50	`boot/boot.asm` contains both a Multiboot 2 header and a Multiboot 1 header in the `.mb2hdr` section, producing a single kernel image that GRUB can load via either protocol.
51	
52	### 1.1 Multiboot Headers
53	
54	**Multiboot 2 header** (first, at section start):
55	- Magic: `0xE85250D6`, architecture: `0` (i386 protected mode)
56	- Framebuffer tag (type 5, optional): requests 32 bpp, any resolution
57	- End tag (type 0)
58	
59	**Multiboot 1 header** (immediately after, legacy fallback):
60	- Magic: `0x1BADB002`, flags: align + meminfo
61	
62	GRUB inspects both within the first 32 KiB and selects the protocol matching the loaded menu entry.
63	
64	### 1.2 Page Tables
65	
66	Four PD tables (`p2_table_0`..`p2_table_3`) each map 512 × 2 MiB = 1 GiB:
67	
68	```
69	PML4[0] → PDPT
70	PDPT[0] → p2_table_0  (0x00000000 – 0x3FFFFFFF)
71	PDPT[1] → p2_table_1  (0x40000000 – 0x7FFFFFFF)
72	PDPT[2] → p2_table_2  (0x80000000 – 0xBFFFFFFF)  ← GOP framebuffer
73	PDPT[3] → p2_table_3  (0xC0000000 – 0xFFFFFFFF)
74	```
75	
76	Total coverage: **4 GiB** via 2 MiB huge pages. Required because the GOP framebuffer under QEMU virtio-gpu resides at `0x80000000`.
77	
78	### 1.3 Entry Flow
79	
80	```
81	[32-bit protected mode]
82	_start:
83	  1. Preserve MB magic (EAX) + info pointer (EBX) → RDI / RSI
84	  2. Verify CPUID support (toggle ID flag in EFLAGS)
85	  3. Verify long-mode support (CPUID leaf 0x80000001, bit 29)
86	  4. Build identity-mapped page tables (4 GiB, 2 MiB huge pages)
87	  5. Load PML4 into CR3
88	  6. Set CR4.PAE, CR4.OSFXSR, CR4.OSXMMEXCPT
89	  7. Set EFER.LME via MSR 0xC0000080
90	  8. Set CR0.PG (enable paging → activates long mode)
91	  9. Load 64-bit GDT stub
92	 10. Far-jump to long_mode_start (CS selector 0x08)
93	
94	[64-bit long mode]
95	long_mode_start:
96	 11. Zero all segment registers (DS, ES, FS, GS, SS)
97	 12. Zero-extend RDI / RSI (EAX / EBX from 32-bit entry)
98	 13. Call kernel_main(mb_magic, mb_info_phys)
99	```
100	
101	### 1.4 kernel_main Sequence
102	
103	```
104	kernel_main(mb_magic, mb_info_phys):
105	  serial_init
106	  if mb_magic == MB2_MAGIC:
107	      walk MB2 tag list → find framebuffer tag (type 8)
108	      gop_init_from_mb2_tag() → vga_init_gop()
109	  else:
110	      vga_init()  (VGA text mode)
111	  vga_clear
112	  gdt_init / idt_init / timer_init / sti
113	  syscall_init / keyboard_init / process_init
114	  detect_cpu
115	  pmm_init_mb2 or pmm_init_mb1
116	  vmm_init
117	  vfs_init / rawfs+ext2 mount / initramfs_seed
118	  minit_init
119	  proc_create(shell_main, RING_SERVICE) → proc_wake → minit_watch
120	  proc_create(voicebox_main, RING_SERVICE) → proc_wake → minit_watch
121	  sched_pick → proc_switch
122	  idle: minit_tick() + hlt
123	```

127	## 2. Memory Layout
128	
129	### Physical Address Space (at boot)
130	
131	| Range | Contents |
132	|-------|----------|
133	| `0x000000 – 0x0FFFFF` | BIOS / legacy (not used) |
134	| `0x100000 – ~` | Kernel ELF loaded here by GRUB |
135	| `0x80000000` (approx) | GOP framebuffer (QEMU virtio-gpu / OVMF) |
136	| Above kernel | Free RAM (tracked by PMM) |
137	
138	### Virtual Address Space (kernel)
139	
140	All physical addresses are identity-mapped — virtual == physical for the first 4 GiB.
141	
142	| Symbol | Address | Description |
143	|--------|---------|-------------|
144	| `.text` start | `0x100000` | Kernel code |
145	| `.data` / `.rodata` | after `.text` | Kernel data |
146	| `.bss` | after `.data` | Zero-init + heap |
147	| `_heap_start` | inside `.bss` | Start of allocator arena |
148	| `_heap_end` | `_heap_start + 64 MiB` | End of allocator arena |
149	
150	The heap is declared inside `.bss` (NOBITS ELF section) so it occupies no space in the binary on disk.

155	
156	### 3.1 Display Driver (VGA + GOP)
157	
158	**Files:** `kernel/vga.c`, `kernel/gop.c`, `include/vga.h`, `include/gop.h`
159	
160	The display layer supports two render paths selected at boot. The active path is recorded in the `use_gop_path` static bool in `vga.c` and `gop_available` in `gop.c`.
161	
162	#### VGA Text Mode Path
163	
164	Mode: 80×25 text, MMIO at `0xB8000`. Cell format: `[attribute][char]` (2 bytes). Active when booted via Multiboot 1 or when GOP initialisation fails.
165	
166	```c
167	void vga_init(void);               /* set 80×25, upload font, set cursor   */
168	void vga_init_gop(void);           /* switch to GOP path, no port I/O      */
169	void vga_clear(void);              /* clear screen to current colour       */
170	void kprint(const char *s);        /* print null-terminated string         */
171	void kprint_char(char c);          /* print single character               */
172	void kprint_uint64(uint64_t n);    /* print decimal integer                */
173	void kprint_hex(uint64_t n);       /* print hex with "0x" prefix           */
174	void kprint_color(const char *s, uint8_t color); /* print with colour override */
175	void vga_goto(size_t col, size_t row); /* move cursor; clamps to grid      */
176	```
177	
178	Grid dimensions are computed dynamically:
179	- VGA path: fixed 80×25
180	- GOP path: `fb_width / 8` × `fb_height / 16`
181	
182	`vga_putchar` and `vga_scroll` use these dynamic dimensions so both paths handle wrapping and scrolling correctly.
183	
184	**Font:** 8×16 glyphs in `boot/font8x16.asm`. On VGA, uploaded to plane 2 at boot. On GOP, blitted directly from the same array by `gop_draw_glyph`.
185	
186	#### GOP Framebuffer Path
187	
188	**File:** `kernel/gop.c`, `include/gop.h`
189	
190	Active when Multiboot 2 provides a framebuffer tag with `bpp ≥ 15`.
191	
192	```c
193	typedef struct {
194	    uint64_t addr;          /* physical base address of framebuffer */
195	    uint32_t width;         /* pixels per row                       */
196	    uint32_t height;        /* rows                                 */
197	    uint32_t pitch;         /* bytes per row (may include padding)  */
198	    uint32_t bpp;           /* bits per pixel (typically 32)        */
199	    uint8_t  red_pos;       /* bit position of red channel          */
200	    uint8_t  green_pos;
201	    uint8_t  blue_pos;
202	} gop_info_t;
203	
204	extern gop_info_t gop_fb;
205	extern bool       gop_available;
206	
207	bool gop_init_from_mb2_tag(const gop_mb2_tag_t *tag);
208	void gop_draw_glyph(uint32_t px, uint32_t py, const uint8_t *bitmap,
209	                    uint32_t rows, uint32_t fg, uint32_t bg);
210	void gop_fill_rect(uint32_t x, uint32_t y, uint32_t w, uint32_t h, uint32_t rgb32);
211	void gop_clear(uint32_t rgb32);
212	
213	static inline uint32_t gop_pack_color(uint8_t r, uint8_t g, uint8_t b);
214	```
215	
216	**QEMU virtio-gpu quirk:** QEMU reports `framebuffer_type=1` (indexed colour) even though the buffer is a 32 bpp BGRX direct-colour surface at `0x80000000`. `gop_init_from_mb2_tag` accepts `type != 2` when `bpp >= 15` and hardcodes the BGRX channel layout (red_pos=16, green_pos=8, blue_pos=0).
217	
218	**`SYS_PUTCELL`** draws a single character cell at `(col, row)` without advancing the global cursor, enabling userland to implement full-screen UIs without touching kernel cursor state.

239	### 3.3 IDT & Exceptions
240	
241	**File:** `kernel/idt.c`, `boot/isr_stubs.asm`
242	
243	256 interrupt gates, all installed at `idt_init()`. The stub macro in `isr_stubs.asm` pushes a uniform `int_frame_t` layout (error code + vector number) then calls the C handler.
244	
245	CPU exceptions (vectors 0–31) print the vector number and faulting RIP to the display, then `hlt`.
246	
247	Hardware IRQs (vectors 32–47) are dispatched through the IRQ handler table. IRQ0 drives the timer; IRQ1 drives the keyboard.
248	
249	`int $0x80` (vector 128) is patched to DPL=1 by `syscall_init()` so Ring-1 code can invoke it without a GPF.

285	
286	**File:** `kernel/process.c`, `include/process.h`, `include/sched.h`
287	
288	Each process has a `process_t` PCB:
289	
290	```c

292	    uint64_t   rsp;             /* saved stack pointer (context switch) */
293	    uint64_t   rip;             /* entry point                          */
294	    uint32_t   pid;

320	
321	**File:** `kernel/pmm.c`, `kernel/vmm.c`
322	
323	**PMM** tracks 4K physical frames using a bitmap derived from the boot memory map. Two init paths:

336	### 3.8 minit — Process Supervisor
337	
338	**File:** `kernel/minit.c`, `include/minit.h`
339	
340	minit is NephilimOS's lightweight init. It runs inside the kernel idle loop — no separate process, zero overhead.
341	
342	**Configuration:**
343	
344	```c
345	#define MINIT_MAX_WATCH  16   /* max supervised processes */
346	#define MINIT_MAX_RETRY   3   /* restart attempts before giving up */
347	```
348	
349	**API:**
350	
351	```c
352	void minit_init(void);
353	int  minit_watch(void (*entry)(void), const char *name, process_t *p);
354	void minit_tick(void);   /* call from idle loop on each hlt iteration */
355	```
356	
357	**Behaviour per tick:**
358	1. For each active slot, call `proc_by_pid(w->pid)`.
359	2. If the process is alive (`state != PROC_UNUSED && state != PROC_ZOMBIE`), skip.
360	3. If dead and `retries < MINIT_MAX_RETRY`: increment retries, log the attempt, `proc_create` + `proc_wake`, update `w->pid`.
361	4. If `retries >= MINIT_MAX_RETRY`: log "giving up", clear the slot.
362	
363	**Watched processes:** `shell` (PID 1) and `VoiceBox` (spawned immediately after the shell).
364

367	### 3.9 VoiceBox — Audio Driver
368	
369	**File:** `drivers/voicebox.c`, `include/voicebox.h`
370	
371	VoiceBox is a kernel-side audio driver exposed as a Ring-1 process supervised by minit. It probes four backends in priority order at boot, activates the best one, plays a confirmation chime, then idles.
372	
373	#### Backend Priority
374	
375	| Priority | Backend | Probe method |
376	|----------|---------|-------------|
377	| 1 | **SB16** | DSP reset sequence at I/O bases 0x220/0x240/0x260/0x280; expects 0xAA echo; version ≥ 4.x |
378	| 2 | **AC97** | PCI scan (bus 0–7) for vendor:device pairs (Intel ICH/ICH0/ICH2/ICH3/ICH4, AMD); reads I/O BARs; cold-resets codec; sets master volume to max |
379	| 3 | **ISA speaker** | Always succeeds — PIT channel 2 (port 0x42/0x43) + speaker gate (port 0x61 bits 0–1) |
380	| 4 | **HDA (stub)** | PCI scan for Intel/AMD/NVIDIA HDA vendor:device IDs; detected and logged, no playback implemented |
381	
382	#### Tone Generation
383	
384	- **SB16:** Enables DSP speaker (`0xD1`), programs PIT channel 2, disables speaker (`0xD3`) when done.
385	- **AC97 / HDA:** No hardware tone generator — falls through to ISA speaker for `vb_beep()`.
386	- **ISA speaker:** Programs PIT channel 2 in mode 3 (square wave), enables gate via port 0x61.
387	
388	Duration is measured by busy-waiting on `timer_ticks` (100 Hz PIT).
389	
390	#### Public API
391	
392	```c
393	typedef enum {
394	    VB_BACKEND_NONE, VB_BACKEND_ISA, VB_BACKEND_SB16,
395	    VB_BACKEND_AC97, VB_BACKEND_HDA,
396	} vb_backend_t;
397	
398	void         vb_init(void);
399	void         vb_beep(uint32_t freq_hz, uint32_t duration_ms);
400	void         vb_stop(void);
401	vb_backend_t vb_active_backend(void);
402	const char  *vb_backend_name(void);
403	void         voicebox_main(void);   /* minit entry point */
404	```
405	
406	#### Boot Chime
407	
408	`voicebox_main` calls `vb_init()` (which runs all probes and logs results), then plays a single 1000 Hz / 120 ms confirmation tone before entering its idle `hlt` loop.
409	
410	#### Userland Access
411	
412	`SYS_BEEP` (syscall 41): `rdi`=freq_hz, `rsi`=duration_ms. Calls `vb_beep()` synchronously in the syscall handler — the calling process blocks for the duration.

417	
418	**File:** `kernel/syscall.c`, `include/syscall.h`
419	
420	Invoked via `int $0x80`. Convention:

490	**`fb_info_t` struct (returned by `SYS_FB_INFO`):**
491	
492	```c
493	typedef struct {
494	    uint32_t fb_width;    /* framebuffer width in pixels  (0 if VGA) */
495	    uint32_t fb_height;   /* framebuffer height in pixels (0 if VGA) */
496	    uint32_t char_cols;   /* character grid width                     */
497	    uint32_t char_rows;   /* character grid height                    */
498	    uint32_t cell_w;      /* pixels per cell (8)                      */
499	    uint32_t cell_h;      /* pixels per cell (16)                     */
500	    uint8_t  mode;        /* 0=VGA text, 1=GOP                        */
501	} fb_info_t;
502	```
503	
504	**`SYS_PUTCELL` packed argument:** `char | (attr << 8)`. `attr` is a VGA palette byte (foreground nibble | background nibble << 4). On the GOP path, the driver translates the 16-colour palette to 24-bit RGB before blitting.
505	
506	**Shutdown / Reboot implementation:**
507	
508	`SYS_SHUTDOWN` tries in order: QEMU ACPI PM1a (port `0x604`, value `0x2000`), PIIX4 legacy (`0xB004`), microvm/virt (`0x4004`), then `cli; hlt`.
509	
510	`SYS_REBOOT` tries in order: ACPI/PCIe reset register (port `0xCF9`, value `0x06`), PS/2 controller pulse (port `0x64`, value `0xFE`), then `cli; hlt`.
511

517	| `ESYS_BADARG` (-2) | Invalid argument |
518	| `ESYS_NOMEM` (-3) | Process table full |
519	| `ESYS_NOPROC` (-4) | No such PID |
520	| `ESYS_PERM` (-5) | Privilege violation |

660	## 6. Heap Allocator
661	
662	**File:** `stdlib/malloc.c`
663	
664	First-fit free-list allocator with immediate coalescing.
665	
666	**Block header (16 bytes):**
667	
668	```c
669	typedef struct block {
670	    size_t        size;    /* usable payload bytes */
671	    uint32_t      free;    /* 1 = free, 0 = allocated */
672	    uint32_t      _pad;
673	    struct block *next;
674	} block_t;
675	```
676	
677	**`malloc(n)`:** First-fit walk; splits if remainder ≥ 32 bytes.
678	
679	**`free(ptr)`:** Marks free, coalesces adjacent free blocks.
680	
681	**`realloc(ptr, n)`:** In-place if block is large enough; otherwise malloc + memcpy + free.
682	
683	**Arena:** `_heap_start` to `_heap_end` (64 MiB in `.bss`). Initialised lazily on first `malloc`.
